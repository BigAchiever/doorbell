Doorbell

Overview

Operator Token Required

The dashboard shows captured request and response bodies, so it is not public.

Open It From a Link

Visit this once and the token is stored in a cookie for a week:

/dashboard?token=<your DOORBELL_ADMIN_TOKEN>

Or Call the API Directly

curl -H "Authorization: Bearer $DOORBELL_ADMIN_TOKEN" \
  https://your-gateway/api/requests

The token is the same one your doorbell CLI uses. Tunnels themselves keep working without it — only the operator view is gated.
