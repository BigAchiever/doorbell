Overview

Paste your operator token

The dashboard replays captured request and response bodies, so it stays behind a token. Your tunnels keep running without it - only this view is gated.

Remembered on this device for 7 days, in a cookie that is HttpOnly, SameSite=Lax and - behind the Zerops balancer - Secure.

Don't have one?

Then you don't need one. Nothing this project claims depends on this view: the overview page carries the live counters and the timeline, and two curl commands at the top of the README will hold a real request in front of you.

Only this page is gated, and only because it serves captured request bodies and can re-send them.

If you run this gateway

It is DOORBELL_ADMIN_TOKEN, in the gw service's environment variables. Not the token your CLI passes - that one is DOORBELL_CLIENT_TOKEN, and it opens tunnels without opening this.

curl -H "Authorization: Bearer $TOKEN" \
  https://your-gateway/api/requests
